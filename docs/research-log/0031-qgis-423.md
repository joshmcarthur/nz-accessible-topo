# 0031 — Square draws use QGIS 4.2.3

**Date:** 2026-11-02

## Question

Can QGIS 4.2.3 on this Mac draw the 1 km squares?

## What we did

Drew the four squares for stock and for accessible with `/Applications/QGIS-final-4_2_3.app`. The interpreter is `Contents/MacOS/python3.12`. `PROJ_DATA` points at `Contents/Resources/qgis/proj`.

## What we found

The app is QGIS 4.2.3-Belém do Pará. It opens the project. `Map5View` has 38 layers.

Eight squares took about 130 seconds. The same eight squares on the emulated map image took 46 minutes.

The estuary name is upright. The hot-pink pixel count is 0. The pictures match the container squares.

A draw with no `PROJ_DATA` writes a white square. The app Python does not start unless `PYTHONHOME` is `Contents/Frameworks`.
