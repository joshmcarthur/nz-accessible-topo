## What the images show (observations, grade D)

1. **Greyscale and red light are where LINZ's style fails hardest.** Scrub and
   scattered scrub merge into one shape; contours nearly vanish under red
   light; the closed-track shadow disappears; the red "Pā site" label goes
   paper-white under red light. In `accessible-v0` the stipple, cross-bars,
   contours and darkened label survive all six conditions.
2. **Dichromat simulations change less than expected for LINZ** — consistent
   with the audit (most LINZ problems are *lightness*, not hue).
3. **Darker contours make the map busier.** Even on synthetic terrain, the
   v0 intermediates compete with tracks and labels on steep slopes. This is
   OQ-09 made visible: a likely next step is a lighter intermediate (still
   ≥3:1) or thinner intermediates at z13–14.
4. **Relief:** NW→NNW is a subtle visual change. These images can show *what*
   changes; whether it reduces terrain-reversal errors is a perception
   question for user testing (R-16), which the cited studies measured.
5. **Water labels** read as clearly "water" from colour alone once upright;
   the italic carried less information than expected.
